# Каталог компонентов Pole Mobile 2.0

Снимок знаний на 2026-10-09. Источник: файл Pole Mobile 2.0 (`tN0vhB9QeckIvUKC6T8zWb`), страница «Компоненты 🍏» (`9095:6361`): на странице каждого компонента есть вкладки «Правила использования», «Возможности», «Анатомия». Если здесь что-то расходится с Figma, прав Figma.

Этот файл нужен, чтобы по блоку в макете определить, **какой компонент ДС должен тут стоять**, и понять, собран ли блок из него, собран ли руками или использован не по назначению.

## Как читать названия

| Признак | Значение |
|---|---|
| `🍏 Имя` | Компонент ДС. Его и нужно брать из Assets |
| `.🔶 Имя`, `🔶 Имя`, `.Имя` | Служебный блок внутри компонента или «Ядро». В гайдах: «не компонент, для работы только команды ДС». Дизайнер не должен вставлять его в макет напрямую |
| `🚧 Имя` | Компонент в разработке. Пометь «уточнить», не нарушение |
| `[ver 1.0]`, `[ver 2.0]` | Две версии одного компонента (List, Notification). Что из них целевая, в гайдах не сказано: ver 1.0 не флагай как устаревший, ставь в «уточнить» |
| `[Prod]`, `[Target]` | Tab Bar: Prod для текущего приложения, Target для будущего суперапа |
| Описание компонента начинается с «Компонент ДС» | Подтверждает, что это компонент ДС |

## Как использовать каталог при ревью

Для каждой секции макета определи **роль** каждого блока (ячейка списка, кнопка, чип, баннер, заголовок секции и т.д.) и найди её в таблице «Роль → компонент». Дальше три случая:

1. **Блок является инстансом нужного компонента.** Проверь свойства (раздел «Чего не делать» ниже) и что не скрыты слои вручную.
2. **Блок собран из рамок, текстов и картинок, а в таблице для этой роли есть компонент.** Это самодельная сборка. Пиши как нарушение: назови компонент и как его взять (Assets → Компоненты 🍏). Если в компоненте нет нужного варианта: «запрос в приёмную ДС».
3. **В таблице для этой роли нет компонента.** Не флагай: это может быть компонент продуктовой команды (`🍋`, например карточка товара, Category Cell, Cart Layouts) или паттерн. Отправь в «Нужно уточнить» с вопросом, из какой библиотеки блок.

Подтверждай детач и самодельную сборку по структуре (метаданные ноды: `frame` вместо `instance`, свои id у внутренних слоёв, ручные сдвиги картинок), а не по внешнему виду.

## Правила по компонентам

Каждый блок: **Назначение**, **Свойства** (то, чем управляют вид), **Чего не делать** и **Признак самодельной версии**. Свойства перечислены по именам в Figma.

### Accordion (`25247:61435`)
- Назначение: скрыть/показать большой или необязательный контент по клику на заголовок.
- Свойства: Open On/Off, Icon, Value, Divider.
- Чего не делать: не использовать для важного контента. Заголовок короткий, говорит, что внутри.
- Самодельная: строка с заголовком и шевроном, нарисованная рамкой.

### Background Blur (`81339:24697`)
- Только как фон внутри другого компонента (плавающая панель, карточка поверх контента). Не отдельный элемент.
- На Android ниже 12 блюр отключается: в макете нужна альтернатива без блюра с достаточным контрастом.
- Ставится под контентом, абсолютное позиционирование.

### Badge / Badge Dot (`38824:4533`, `30382:5373`)
- Назначение: числовые уведомления, статусы, метки. Неинтерактивный. Текст 1–2 слова, без точки.
- Свойства: Size L/M/S, Type Primary/onSecondary, Border, Title.
- Самодельная: кружок с цифрой поверх иконки.

### Bottomsheet (`56257:471`) и Header (`2100:52782`)
- Назначение: дополнительный контент снизу, остаться в контексте страницы. Модальная (с затемнением) или немодальная (постоянная).
- Свойства: Type (Info, Custom content, Radio list, Switch list, Checkbox List, List), количество List 2–10, Footer, Legal note, слот Content, Header: Drag bar, Description.
- Чего не делать: не размещать важное и критичное; не делать вложенные шторки. Заголовок 1–3 слова.
- Слот: блок «Замени меня» удаляют или заменяют на инстанс; в слот можно положить любые фреймы.
- Самодельная: белая рамка со скруглением сверху и полоской-драгбаром.

### Button (`124:41824`)
- Типы Base: Primary (одна на экран), Secondary, Border (мягкая замена Secondary), Tertiary, Loyalty (одна на экране, программа лояльности), MPay, Premium, Neutral (только розыгрыши), Transparent, Transparent Inverted; Invert Primary/Tertiary для тёмных и цветных фонов.
- Размеры: Large 48, Small 32. Round button: Large/Small. Inline button 28/24.
- Свойства: Label, Comment, Icon left, Icon right, State (Default/Pressed/Disable/Loading).
- Чего не делать: больше одной Primary на экран; перенос текста внутри кнопки; имитация Pressed/Disabled. Текст инфинитивом совершенного вида («Купить», «Оплатить»), в навигации существительное («Подробнее об акции»).
- Самодельная: рамка с радиусом и текстом по центру.

### Checkbox (`25241:60964`)
- Назначение: множественный выбор. Позиционировать справа, исключение: согласие на обработку данных.
- Свойства: Checked, Indeterminate (частичный выбор в группе), State.
- В списке выбора берут `List` с чекбоксом и кнопку «Применить».

### Chips (`54431:68311` Chips Kit)
- Назначение: фильтровать и группировать по категориям, запускать действия. Можно выбирать несколько.
- Свойства: Chip 2…9 (количество), Wrap, onSecondary; внутри Chip: Icon (слева/справа/только), Counter, Badge, Selected, State.
- Чего не делать: менять иконки у выбранного; иконка слева либо у всех, либо ни у одного (допустимо в одном для акцента); текст 2–3 слова, без переноса, максимум ширины 328; не использовать как навигацию (для этого Tabs). Горизонтального скролла в компоненте нет.
- Самодельная: ряд скруглённых пилюль с текстом.

### Description list (`10773:10982`)
- Пара «метка-значение» с иконкой или кнопкой. Свойства: Label, Placeholder (описание), Action, Button, Icon Button. Метка 1–2 слова.

### Divider (`169:111718`, `17201:58449`)
- Разделение частей контента. Не рисовать линиями (rectangle 1px).

### Empty State (`25215:50740`)
- Medium для экрана или шторки, Small для секции (`🚧`).
- Свойства: Primary Button, Secondary Button, Illustration, Button.
- Чего не делать: не использовать для ошибок прав доступа. Размеры картинки: 280 (экран), 112 (шторка), 40 (секция). Всегда призыв к действию.

### Filter (`63737:9453` Filter Kit)
- Фильтрация по одной категории из группы. Текст 1–2 слова, существительное, без глагола. Иконку справа менять нельзя. Если можно выбрать любое число, то Chips Kit.

### Input (`38996:859`)
- Однострочный ввод. Свойства: Lead Icon, Lable, Description, Prefix, Suffix, Clear, Trail Icon, State, Filled, Error.
- Для длинного текста Text Area, для кода Input Code, для выбора из вариантов Select. Placeholder вместо label допустим.

### Input Code (`25326:14213`)
- Код подтверждения 4/5/6 ячеек. State: Default/Input/Filled/Error/Success.

### Imaged Selector (`70684:5967`)
- Выбор категории с картинкой. Цвет задаётся темой. Выбранный: фон и двойной stroke вокруг картинки.

### Label (`25250:17805`)
- Свойства: Usage (тип), Size S/XS, Lead Icon, Trail Icon, Arrow, Border, Label text.
- Стрелка только в размере S. Цвета из админки (кроме лояльности), новый цвет через приёмную. Бордер, когда лейбл сливается с фоном.
- Самодельная: цветная плашка с текстом. Проверяй: цвет и скругление должны совпадать с типом Usage.

### List (`87133:19601` ver 2.0, `38592:2036` ver 1.0)
- Вертикальный список однотипных данных, интерактивных элементов.
- Свойства (ver 2.0): Size Medium/Small, Lead (иконка 24/32/40), Trail (Icon, Arrow, Switch, Checkbox, Radio, Button, Badge, Dot, Label, Icon 40), Divider, Padding Divider; тексты Title, Subtitle (Primary/Secondary), Title Accent, Value, Subvalue.
- Чего не делать: между компонентами в группе доп отступ не ставить; иконка выравнивается по базовой линии первой строки, не по центру; Title до 4 строк, Value и Subvalue в одну.
- Самодельная: строка из рамок «иконка, два текста, значение справа». Типичная находка: ячейка собрана рамками вместо List.

### Loader (`6345:9812` и др., `169:111896`)
- Small (Primary, Project, Invert Primary; размеры 16/24/32/40) для компонентов, Big для страниц и шторок. Когда время операции неизвестно.

### Loyalty Label / Magnets (`25551:4522`)
- Свойства: Text, Text 2, Gradient, Icon, Size.

### Menus (`1962:51155`)
- Выпадающее меню из List. Для действий с одним объектом и второстепенных действий.

### Notification (`88028:2188` Normal ver 2.0, `6199:4165` Small)
- Встроенное сообщение внутри страницы (не поверх контента: для этого Toast).
- Типы: Info (серая кнопка можно сменить на акцентную красную), Success, Warning, Error, Bright (Accent), Outline, Invert Primary.
- Свойства (Normal ver 2.0): Variant Close/Next, Placement In Section / Between Section, Lead (иконка/иллюстрация), Buttons, Secondary Button, Comment, Label text, Trail. Small: Variant Button/Next/Action.
- Чего не делать: Accent не больше одного на экране; смена иконки слева только у Info и Bright; одна кнопка делается Primary; заголовок не длиннее двух строк.

### Overlay (`455:151987`)
- Default для затемнения под модалками и шторками, Loading для блокировки экрана.

### Progress bar (`22929:1014`)
- Свойства: Label, Subtitle, Type bar (Mono, Steps). Тексты: Label (название процесса), Value, Optional text. Меньший текст: стиль Caption/Small/Accent low.

### Radiobutton (`25215:60692`)
- Один из взаимоисключающих вариантов; всегда группой, минимум 2; по умолчанию выбранный первым. В списке через `List`.

### Refresh Control (`37977:31804`)
- Только iOS, ничего не рисовать руками.

### Search (`25326:14941`)
- Свойства: Button, Placeholder, Lead Icon, Trail Icon, State. Иконка слева по умолчанию лупа (можно логотип магазина). При скролле белый фон без тени и бордера.

### Section (`91130:11551`)
- Секция-контейнер: фон, скругление, отступы задаёт он. Position (Top/Middle/Bottom) регулирует скругления. Section [Ribbon]: Position Ribbon None/Top/Bottom.
- «Улыбка»: максимум две строки текста без заголовка, только иконки-кнопки (не текстовые), сложные картинки только на сплошном фоне, выравнивание как у контента секции. Одна на экран.
- Заголовок секции остаётся; заменяется только содержимое.

### Segmented control (`70006:6101`)
- 2–3 (до 4) взаимоисключающих варианта, один всегда активен (по умолчанию левый). Type: Default/Transparent.

### Select (`39062:5636`)
- Поле выбора из готовых вариантов. Список: Bottomsheet для многих, Menu для 4–6.

### Skeleton (`91816:12308`)
- Тип по фону: Default (белый), Static Black (светлый цветной), Static White (тёмный цветной). Для каждого компонента в макете делают скрываемый слой.

### Slider (`56932:30160`), Slider Dots (`135:51535`), Slider Icons (`61773:11897`)
- Slider: Single / Range (свойство Range), Input, Value Labels.
- Dots: Large для карточек товара, Small для мини-карточек. Icons: дополнительный индикатор, когда в карусели видео.

### Stepper (`935:12356` M, `935:12335` S, `3028:31046` XS, `37100:11777` Border)
- Выбор количества. M основной, S плотный, Border для узких карточек. Единицы измерения (гр, кг, шт, уп, л) зашиты. Status: Default/Max/Min/Del.

### Switch (`25241:60748`)
- Двоичные состояния. Справа от подписи, активное состояние для позитивного действия. В списке через `List`.

### Tab Bar (`70563:2438` Prod, `69541:42290` Target)
- Главная навигация. Не показывается при шторке и модальном окне, и когда на странице важное целевое действие. Индикатор уведомления добавляется в свойствах. Иконки новых разделов приносят продуктовые команды.

### Tabs (`25215:60327` Tabs, `48721:3304` Segmented, `25527:63114` Underlined Kit, `63737:11952` Tabs Kit)
- Segmented: навигация 1-го уровня, 2–3 вкладки, статичный. Underlined Kit: 1-го уровня, скролл, до 6. Tabs Kit: 2-го уровня внутри секций.
- Чего не делать: Tabs Underlined/Segmented не использовать внутри секции; Tabs Kit не для навигации страницы. Один таб всегда активен. Названия существительными. Иконка на всех табах или ни на одном.

### Text Area
- Многострочный ввод, фиксированная высота, дальше скролл; лимит символов счётчиком.

### Text Text (`58322:11879`)
- Свойства: Icon Left/Right, Text Left/Right, Size Large/Medium, Sale. Заголовочный вариант для «Итого».

### Title (`72892:17048`)

### Toast (`58298:9154`)

### Top navigation (`25250:14202`, `25250:14283` и др.)
