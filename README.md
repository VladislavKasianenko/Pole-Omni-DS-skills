# Pole Omni DS skills

Скилы для Claude по работе с дизайн-системой Pole Omni. Каждый скил лежит в своей папке `skills/<имя>/` и описан файлом `SKILL.md`; дополнительные материалы лежат рядом в `references/`.

## Скилы

| Скил | Что делает |
|---|---|
| [design-review](skills/design-review/SKILL.md) | Ревью макетов продуктовых дизайнеров в Figma: сравнение с эталонными макетами, гайдами ДС и Checklist DS. Только читает Figma, ничего не меняет |

## Структура

```
skills/
└── <имя-скила>/
    ├── SKILL.md          # frontmatter (name, description) и инструкции
    └── references/       # справочные материалы, которые скил читает по ходу работы
```

## Как добавить новый скил

1. Создайте папку `skills/<имя-в-kebab-case>/` и положите в неё `SKILL.md` с frontmatter (`name`, `description`).
2. Длинные справочные материалы вынесите в `references/` и сошлитесь на них из `SKILL.md`.
3. Добавьте строку в таблицу скилов выше.
